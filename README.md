# 🎵 Spotify Clone

A Spotify-inspired music player built using **HTML, CSS, and JavaScript**.  
It features a responsive interface, custom audio controls, and interactive playlists, providing a simple yet engaging way to explore core web development concepts.

---

## 🚀 Features
- 🎧 Play, pause, next, and previous song controls  
- 📂 Playlist management  
- 📱 Responsive design (mobile + desktop)  
- 🎨 Spotify-like UI using pure CSS  
- 🔊 Real-time audio progress bar  

---

## 🛠️ Tech Stack
- **HTML5** – structure of the app  
- **CSS3** – styling and layout  
- **JavaScript (ES6)** – functionality and interactivity
